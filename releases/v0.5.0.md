## Testing / agent policy

Default layers:

```text
Jest + jest-expo
→ React Native Testing Library
→ Expo Router testing utilities
→ Maestro deterministic E2E
→ agent-device exploratory verification/evidence
→ XcodeBuildMCP only when native iOS depth is needed
```

Agents do not replace deterministic regression coverage.
